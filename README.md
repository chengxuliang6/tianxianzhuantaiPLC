# 天线测试转台控制

本项目为 Easy521-0808TN PLC、SV660N 伺服和天线转台提供 Windows 控制界面、PLC 参考程序及逐度时间戳 CSV。当前版本支持先用纯软件模拟器熟悉操作；真实设备仍需现场核验后才能运动。

## 使用的硬件

| 硬件 | 型号/规格 | 用途 |
|---|---|---|
| PLC | Easy521-0808TN | 运行转台控制逻辑、EtherCAT 轴控制和 Modbus TCP 寄存器服务 |
| 伺服驱动器/电机 | 汇川 SV660N 系列及配套多圈编码器电机 | 驱动转台并提供位置、速度反馈 |
| 大小齿轮 | 120:24，即 5:1 | 一级机械减速 |
| 行星减速器 | 暂定 10:1 | 二级机械减速；与齿轮组成总减速比 50:1 |
| 天线转台 | 连续坐标范围 -360°～+360° | 安装天线并执行手动/自动正反转测试 |
| Windows 电脑 | 带以太网口 | 运行中文控制程序、记录逐度 CSV |
| 普通以太网线 | RJ45 | 电脑网口连接 PLC `EtherNET1`，用于 Modbus TCP |
| EtherCAT 网线 | 按现场伺服接口要求 | PLC EtherCAT 主站连接伺服 `CN3` |
| Type-C 数据线 | USB Type-C | 仅用于 PLC 编程和在线调试，不能替代 Modbus TCP 网线 |

当前没有实体急停按钮。软件停止和通信心跳都不能替代实体急停或安全回路。

## 使用的软件

| 软件 | 版本/要求 | 用途 |
|---|---|---|
| Windows | Windows 10/11 64 位 | 运行控制界面和打包程序 |
| AutoShop | 与 Easy521 固件匹配的现场版本 | 编译、下载和在线查看 PLC 程序；实际版本需现场记录 |
| Python | 3.12.x，当前验证为 3.12.13 | 运行源码版电脑控制程序 |
| PySide6 | 6.11.1 | 中文 Windows 图形界面 |
| pymodbus | 3.14.0 | 电脑与 PLC 的 Modbus TCP 通信 |
| pytest / pytest-qt | pytest 8.x、pytest-qt 4.x | 自动化和离屏界面测试 |
| PyInstaller | 6.x，当前打包验证为 6.22.0 | 生成 `TurntableControl.exe` |

项目提供两种电脑端运行方式：推荐先使用本地模拟器熟悉流程；回到现场并完成安全、编译、字序和轴配置核验后，再使用真实 PLC 模式。

## 安全边界

界面中的红色“停止（软件）”和通信心跳都不是实体急停，也不是安全等级功能。当前现场没有实体急停，因此在实体急停、机械限位和安全隔离完善前，只允许空载、人员远离、1°/s 的受控初次调试；不得带载或高速运行。

## 现场协议门禁（v2）

现场交付只使用协议版本 `2`：`D0:D19` 是命令/参数，`D100:D120` 是状态/运行元数据，`D200:D206` 是协议/时间同步，`D2000:D4159` 是原始逐度事件字。旧程序或空白 PLC 必须先在伺服禁用、静止且无 PC Modbus 写入的条件下，完成离线零错误零警告编译、取得用户一次性授权并通过 Type-C 下载 v2 程序。下载后重新连接并只读 `D200:D202`：`D200` 必须为协议版本 `2`，`D201:D202` 必须依次为 `0x1234`、`0x5678`；再确认 `D100:D120` 为静态安全状态。门禁不匹配时停止，禁止 PC 写入、伺服使能和运动。

方向编码为正转 `+1`、反转=-1。PLC 重启后，即使 `D2000:D4159` 的原始字仍可读，旧事件字无效，绝不得导出或确认；必须等待新的事件计数、代次和运行状态。

模拟器不会连接 PLC、不会访问网络，也不会产生真实运动。它只能验证软件流程，不能证明实际方向、角度、停止距离或机械安全。

## 接线边界

- 电脑网口 → 普通网线 → PLC `EtherNET1`，用于 Modbus TCP。
- PLC EtherCAT 主站 → 伺服 `CN3`，用于轴控制。
- Type-C 线仅用于 PLC 编程/在线调试，不能替代电脑与 PLC 的 Modbus TCP 网线。
- 大小齿轮比为 `120:24 = 5:1`，行星减速器暂定 `10:1`，总减速比为 `50:1`。

转台速度与电机速度：

| 转台速度 | 电机速度（50:1） |
|---:|---:|
| 1°/s | 8.333 rpm |
| 2°/s | 16.667 rpm |
| 4°/s | 33.333 rpm |
| 5°/s | 41.667 rpm |
| 10°/s | 83.333 rpm |

## 安装

在项目根目录打开 PowerShell：

```powershell
.\scripts\setup.ps1
```

要求 Python 3.12；安装脚本会建立 `.venv` 并安装固定依赖。

## 先运行模拟器

```powershell
.\scripts\run-simulator.ps1
```

窗口标题和连接区会明确显示“模拟器（无 PLC）”。点击连接后，按以下顺序操作：

1. 确认处于模拟器模式并连接。
2. 点击“当前位置设零”，确认人工目视设零。
3. 点击“伺服上电/下电”（模拟器只改变软件状态）。
4. 选择手动/自动、正转/反转及 1、2、4、5、10°/s。
5. 点击启动；自动模式相对运行一圈，手动模式最多运行一圈，连续坐标范围为 -360°～+360°。
6. 需要中止时点击红色“停止（软件）”或按空格键；系统采用平滑停止。
7. 终态后自动保存逐度 CSV，记录 1～360°（中止时为 1～N°）及时间戳；若在跨过第 1°前停止，则只保存一条运行元数据记录，事件字段留空，不伪造角度或时间戳。

默认模拟数据目录为 `data\simulator`。也可指定目录：

```powershell
.\scripts\run-simulator.ps1 -DataDir D:\TurntableData
```

时间字段以 1 ms 为字段分辨率，但这不代表绝对时间精度达到 1 ms。

## 真实 PLC 界面

```powershell
.\scripts\run-app.ps1 --plc-ip 192.168.1.10 --data-dir D:\TurntableData
```

请把示例 IP 换成现场确认的 PLC 地址。程序不会猜测 IP，也不会在点击“连接”之前创建 Modbus 会话。人工设零没有原点开关参与：必须确认转台物理位置安全，再将当前位置定义为 0°。

## Windows 打包

```powershell
.\scripts\build-windows.ps1
```

输出为 `dist\TurntableControl\TurntableControl.exe`。脚本用 `--simulator --package-smoke` 启动真实模拟器 GUI 路径并自动退出，全程不创建网络客户端；`build/`、`dist/` 和自动生成的 `.spec` 不提交到 Git。
