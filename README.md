# 天线平台旋转控制

本项目用于构建 Windows 端的天线转台控制与运行数据记录软件，并与 PLC 的 Modbus TCP 接口配合使用。

## 硬件清单

- Easy521-0808TN PLC
- SV660N 伺服驱动器与电机
- 天线旋转平台及机械限位/安全设施
- 运行 Windows 的控制电脑与以太网连接

## 安全提示

软件中的“停止”仅为软件停止，**不是急停**，不能替代实体急停、安全回路、机械限位或现场安全措施。未配置实体急停时，不得进行有载或高速运动。

## 当前阶段

当前处于 Python 工程初始化阶段；尚未授权任何实际硬件运动或写入操作。

## 安装

在仓库根目录运行：

```powershell
.\scripts\setup.ps1
```

## 测试

激活虚拟环境后运行：

```powershell
python -m pytest pc/tests/test_smoke.py -q
```
