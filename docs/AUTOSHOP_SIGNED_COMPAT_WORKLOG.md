# AutoShop 有符号整数兼容改造工作日志

日期：2026-08-19
分支：`codex/autoshop-int-compat`
软件基线：`f21966c`

## 本次完成内容

AutoShop V4.12 的变量编辑器不提供 `UINT`、`UDINT`。因此 PLC 参考源码已
改为只使用 AutoShop 可见的有符号 `INT`、`DINT`，但未改变以下 Modbus 布局或
变量名称：

- 命令：`D0:D19`
- 状态：`D100:D120`
- 协议：`D200:D206`
- 逐度事件缓冲：`D2000:D4159`

明确填写规则：

- 每个 16 位 D 寄存器字使用有符号 `INT`。
- 已解码的 32 位过程值及 PLC 时钟原始位模式使用有符号 `DINT`。
- 不要在 AutoShop 变量表中使用 `UINT` 或 `UDINT`。
- 必须按十进制填写：`D0011 = -15536`、`D0201 = 4660`、`D0202 = 22136`。

源码还加入了显式回绕处理：DINT 原始时钟在 `2147483647` 后回到
`-2147483648`；事件代际在 `32767` 后回到 `-32768`。逐度时间戳的 32 位
位模式仍为高字在前，且极限边界由静态合同和 Python 参考模型覆盖。
