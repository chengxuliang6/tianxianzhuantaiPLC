# Easy521 转台现场联调清单

状态：待现场执行。本文是操作顺序和记录表，不代表任何现场项目已通过。

## 绝对停止条件

出现以下任一情况立即停止测试、切断伺服动力并排查：方向与指令不符、位置跳变、速度异常、异响/振动、机械干涉、线缆缠绕、报警、EtherCAT 掉站、软件停止未按预期减速、电脑断线后仍继续运动、人员进入旋转区域。

红色“停止（软件）”、空格键和通信心跳都不是实体急停。现场当前没有实体急停，因此只允许空载、人员远离、1°/s 的受控初次调试；不允许带载、整圈或更高速度测试。应明确一名操作员守在电脑和可切断伺服动力的位置。

## A. 不上电/不运动检查

- [ ] 转台空载，旋转范围清空，线缆留有余量，无机械干涉。
- [ ] PLC、伺服、减速器、齿轮与转台固定可靠；总减速比确认暂为 `5 × 10 = 50:1`。
- [ ] 电脑网线连接 PLC `EtherNET1`；Type-C 只用于 PLC 编程；EtherCAT 连接伺服 `CN3`。
- [ ] 操作员知道伺服主电源/动力切断方法，其他人员退出旋转区域。
- [ ] 记录 PLC 型号/固件、AutoShop 版本、伺服型号/固件、电脑网卡名称。

## B. AutoShop 离线编译门禁（本节禁止下载）

- [ ] 参考源码已按 `plc/README.md` 逐页录入并适配当前固件类型名。
- [ ] AutoShop 编译为 `0 error`；警告逐条解释并记录。
- [ ] D1000～D1206、D2000～D4159 变量表绑定与数据类型逐项核对。
- [ ] `Axis_0` 单位、电子齿轮、编码器反馈和 50:1 缩放离线核对完成。
- [ ] 编译结果、警告解释和待适配项已保存；本节不下载程序、不使能轴、不写 PLC。

## C. 只读网络与 Modbus 合同

本节开始前记录明确的 PLC IP；只检查这一张网卡和这一台 PLC，不扫描其他网段。

- [ ] 电脑与 PLC 在同一 IPv4 子网；ping/ARP 对应唯一目标。
- [ ] TCP 502 仅对已确认 PLC 地址做连通性检查。
- [ ] 首先只读 `D1200`，预期协议版本 `1`。
- [ ] 只读 `D1201:D1202`，预期两个 16 位字依次为 `0x1234, 0x5678`，组合为 `0x12345678`。
- [ ] 只读状态块 D1100～D1120，确认轴静止、无故障、实际速度近 0；任何未知枚举或无效反馈均停止。

## E. 首次空载、1°/s、极小位移验证

本节必须由现场人员观察机械运动。首次不得直接自动一圈。

1. [ ] 伺服使能后保持静止，无报警、无爬行；实际速度接近 0。
2. [ ] 人工目视确认物理参考位置后设零，记录设零前后实际位置。
3. [ ] 选择手动、正转、1°/s；启动后观察实际位置，约 1°内立即按软件停止，确认平滑减速并记录最终位置。
4. [ ] 回到安全参考区后选择手动、反转、1°/s，同样在约 1°内停止并记录。
5. [ ] 两次方向均正确、位置连续、停止距离可接受后，才测试拔除电脑—PLC 网线；只允许 1°/s 空载，确认超过 1 s 后受控停止且重连不自动恢复。
6. [ ] 检查 CSV 为严格 1～N；若在跨过第 1°前停止，应只有一条运行元数据记录，事件字段为空。
