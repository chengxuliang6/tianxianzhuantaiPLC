# 天线测试转台 PLC 与电脑控制系统设计规格

## 1. 目标

使用汇川 Easy521-0808TN PLC 通过 EtherCAT 控制 SV660N 伺服驱动器及 MS1H4-40B30CB-A334R 电机，实现天线测试转台的电脑控制。

第一阶段实现可靠的电机与转台运动控制，并记录每次行程经过整数角度时的时间戳及 CSV 数据。KC908A 测量数据的导入与合并不在本阶段实施，但时间字段和文件结构应便于后续匹配。

## 2. 已有硬件与软件条件

- PLC：Easy521-0808TN。
- 伺服驱动器：SV660N，已通过 EtherCAT 与 PLC 连接，AutoShop 可以扫描到设备。
- 伺服电机：MS1H4-40B30CB-A334R，23 位多圈绝对值编码器。
- PLC 编程软件：AutoShop。
- 电脑与 PLC 之间使用普通以太网和 Modbus TCP 通信。
- 当前没有实体急停按钮，第一阶段使用电脑软件停止和 PLC 通信心跳保护进行空载、低速调试。

## 3. 机械传动与工程单位

### 3.1 传动比

- 小齿轮齿数：24。
- 大齿轮齿数：120。
- 齿轮减速比：120 / 24 = 5:1。
- 行星减速器暂定减速比：10:1。
- 总减速比：5 × 10 = 50:1。

因此：

- 电机旋转 50 圈，转台旋转 1 圈。
- 电机旋转 1 圈，转台旋转 7.2°。
- 转台旋转 360°，电机旋转 50 圈。

### 3.2 PLC 工程单位

EtherCAT 轴的程序单位统一定义为转台角度，位置单位为度（°），速度单位为度每秒（°/s），加速度和减速度单位为度每二次方秒（°/s²）。PLC 程序不得使用电机转数作为操作界面的运动单位。

总减速比作为独立参数保存，默认值为 50。更换行星减速器时只修改传动参数和轴换算配置，不修改手动、自动和安全状态逻辑。

PLC 基于电机编码器及总减速比计算转台角度。没有转台输出端编码器时，系统不能直接检测齿轮间隙、机械松动或传动比误差造成的真实转台角度偏差。

## 4. 零点与位置坐标

本阶段不安装原点开关，采用人工设零：

1. 操作者人工将转台刻度指针对准机械 0°。
2. 在电脑控制程序中点击“当前位置设零”。
3. PLC 仅在轴已停止、没有运动命令、伺服无故障时接受设零命令。
4. PLC 将当前绝对编码器位置保存为零点偏移，并置位“零点有效”。

零点偏移使用保持型数据保存。正常断电、重新上电后，绝对编码器状态正常且机械结构未改变时继续使用原零点。发生编码器电池报警、绝对位置丢失、编码器复位、机械拆装或传动机构打滑后，必须清除“零点有效”并重新人工设零。

转台位置使用连续坐标，不把 +360° 或 -360°折算为 0°。允许范围为 -360°～+360°，以便程序判断电缆缠绕方向：

- 到达 +360° 后禁止继续正转，只允许反转。
- 到达 -360° 后禁止继续反转，只允许正转。

## 5. 运动参数

可选转台速度为：

| 档位 | 转台速度 | 对应电机转速 |
|---|---:|---:|
| 1 | 1°/s | 8.333 rpm |
| 2 | 2°/s | 16.667 rpm |
| 3 | 4°/s | 33.333 rpm |
| 4 | 5°/s | 41.667 rpm |
| 5 | 10°/s | 83.333 rpm |

初始运动参数为：

- 加速度：5°/s²。
- 减速度：5°/s²。
- 软件停止减速度：10°/s²。
- 反向间隙补偿：0°，实测后调整。

加速度、减速度和反向间隙补偿作为调试参数保存。运行过程中禁止修改总减速比、加速度、减速度和间隙补偿。

对称加减速且不考虑控制周期量化时，一圈预计时间为：

| 转台速度 | 匀速理论时间 | 含加减速预计时间 |
|---:|---:|---:|
| 1°/s | 360 s | 360.2 s |
| 2°/s | 180 s | 180.4 s |
| 4°/s | 90 s | 90.8 s |
| 5°/s | 72 s | 73.0 s |
| 10°/s | 36 s | 38.0 s |

## 6. PLC 职责与状态机

PLC 独立负责伺服使能、运动规划、方向、目标位置、平滑加减速、软件限位、通信心跳、停止和故障联锁。电脑只发送操作命令和参数，不向伺服周期性发送轨迹点。

建议状态机至少包含：

- 未连接/初始化。
- 未设零。
- 就绪。
- 手动运行。
- 自动运行。
- 正在停止。
- 自动运行已中止。
- 故障。

停止命令优先于启动、模式切换和参数修改命令。

### 6.1 手动模式

1. 操作者选择速度和正转或反转。
2. 点击启动时，PLC 记录本次起始位置。
3. 本次目标位置为“起始位置 ±360°”与全局软件限位的较近者，保证单次运行不超过一圈且绝不越过 -360°～+360°。
4. 运动采用位置控制并按所选速度运行，因此接近目标或软件限位时由 PLC 自动平滑减速。
5. 操作者可以随时点击停止。
6. 停止后保留当前位置；再次启动时重新依据当前位置、方向和全局限位计算可运行距离。

### 6.2 自动模式

1. 操作者选择速度和正转或反转。
2. 自动目标位置严格等于当前位置加 +360° 或 -360°。
3. 如果目标超出 -360°～+360°，PLC 拒绝启动，并返回“该方向空间不足，请反向运行”。
4. 目标有效时，PLC 执行一圈相对位置运动并自动平滑停止。
5. 自动运行期间点击停止，本次测试状态设为“已中止”。下一次启动不得自动续接剩余角度，也不得误认为上一次测试已完成。

## 7. Windows 控制程序

电脑端采用 Python 与 PySide6 开发 Windows 图形界面，通过 Modbus TCP 与 PLC 通信。

界面包含：

1. 连接状态：PLC IP、连接/断开、PLC 在线、EtherCAT 状态、伺服就绪和报警信息。
2. 角度状态：当前位置、目标位置、实际速度、正负软件限位和零点有效状态。
3. 运行设置：手动/自动、正转/反转、五档速度。
4. 操作按钮：伺服使能、启动、停止、当前位置设零、报警复位。
5. 调试参数：总减速比、加速度、减速度和反向间隙补偿。该区域默认收起并防止运行中修改。
6. 数据记录：当前测试编号、已记录角度数量、测试状态、CSV 保存状态和打开数据目录。

软件停止按钮使用醒目的红色外观并始终可操作，同时提供键盘停止快捷键。它属于普通软件停止，不得标注为或宣传为实体急停。

## 8. Modbus TCP 数据约定

电脑与 PLC 之间传输的角度、速度、加速度和减速度采用放大 1000 倍的 32 位有符号整数。例如 10.000°/s 传输为 10000，避免浮点数端序差异。

通信数据分为：

- 命令：模式、方向、速度档位、启动、停止、设零、伺服使能和报警复位。
- 参数：总减速比、加速度、减速度、软件停止减速度和间隙补偿。
- 状态：PLC 状态机、当前位置、目标位置、实际速度、零点状态、软件限位、伺服状态、自动完成、自动中止、逐度记录状态和故障码。
- 心跳：电脑周期递增心跳值，PLC 监测其是否持续更新。
- 逐度事件：测试编号、事件序号、行程角度、带方向的位置角度、PLC 单调运行时间和数据有效标志。

启动、停止、设零和复位等按钮命令使用递增序号或边沿确认机制，避免网络重连后重复执行上一次命令。具体寄存器地址在实施计划中统一分配。

## 9. 通信中断与停止行为

- 电脑在线时持续发送通信心跳。
- 手动或自动运行期间，心跳超过 1 秒未更新，PLC 按 10°/s² 执行软件停止。
- 电脑重新连接后只读取 PLC 当前状态，不自动恢复运动、不补发启动命令。
- 点击电脑软件停止后，PLC 取消当前运动并平滑减速，停止后保持伺服使能和当前位置。
- 以 10°/s 运行并按 10°/s² 减速时，理论停车时间约 1 秒，理论停车距离约 5°。软件停止不是瞬时停车。

## 10. 逐度时间戳与 CSV 记录

### 10.1 测试编号与行程定义

PLC 接受一次手动或自动启动命令时创建一次新测试，电脑为其分配唯一测试编号，例如 `20260811_001`。本次启动位置记为行程 0°，行程角度始终使用正数 1°～360°；方向和带符号的转台连续位置另行保存。

手动运行中途停止时只记录已经经过的整数行程角度，测试最终状态为“手动停止”或“通信中止”。自动运行正常完成时应具有 1°～360°共 360 条角度记录；自动运行中途停止时保留已有记录，最终状态为“自动中止”。停止后再次启动创建新的测试编号，不续写原测试。

### 10.2 PLC 角度事件捕获

PLC 在运动任务中比较上一周期与当前周期的实际编码器换算位置。当行程跨过新的整数角度时，立即生成逐度事件。算法必须支持一个任务周期内跨过多个整数角度的情况，按顺序补齐所有被跨过的角度，不能只记录最后一个角度。

每个事件至少包含：

- 事件序号。
- 行程角度，范围 1°～360°。
- 方向，正转或反转。
- 事件发生时的带符号转台连续位置，单位 0.001°。
- PLC 单调运行时间，分辨率目标为 1 ms。
- 数据有效标志。

事件写入 PLC 本地缓冲区，单次测试容量不少于 360 条。电脑轮询速度或网络短时延迟不得造成角度事件丢失。测试完成或中止后，PLC 保留缓冲区，直到电脑完整读取并确认；未确认的数据不得被下一次测试静默覆盖。电脑在线且成功保存 CSV 后可以自动确认并释放缓冲区。

### 10.3 完整时间戳换算

PLC 保存角度事件发生时的单调运行时间，电脑负责转换为带日期的 Windows 时间。电脑在测试开始前后持续估算 PLC 单调时钟与 Windows 系统时钟之间的偏移，并使用通信往返时间较小的样本更新换算关系。每个角度事件最终生成格式为 `YYYY-MM-DD HH:mm:ss.fff` 的本地时间戳，同时在内部保留 Unix epoch 毫秒值，便于后续程序合并数据。

`1 ms` 是时间字段的记录分辨率，不代表未经验证即可达到 1 ms 的绝对对时精度。实际 Windows—PLC 时间换算误差必须在验收中测量并记录。若以后 KC908A 匹配要求高于软件网络对时能力，应增加共同硬件触发或更高精度的时钟同步方案。

### 10.4 CSV 文件

每次测试单独保存一个 CSV 文件，至少包含：

| 字段 | 含义 | 示例 |
|---|---|---|
| test_id | 测试编号 | 20260811_001 |
| mode | 手动或自动 | AUTO |
| direction | 正转或反转 | CW |
| speed_deg_s | 设定转台速度 | 10.000 |
| travel_angle_deg | 本次行程整数角度 | 25 |
| actual_position_deg | 带方向的连续位置 | 125.003 |
| plc_elapsed_ms | PLC 测得的本次运行时间 | 2501 |
| pc_timestamp | Windows 本地完整时间 | 2026-08-11 14:23:45.123 |
| epoch_ms | Unix epoch 毫秒 | 1786429425123 |
| run_status | 正常完成、手动停止或中止 | COMPLETED |

CSV 使用 UTF-8 编码。运行状态在测试结束后统一写入各行或作为明确的测试元数据保存，不能把中止测试误标为正常完成。程序界面显示保存成功或失败；保存失败时 PLC 缓冲区不得自动清除。

## 11. 联锁与故障处理

出现以下任一条件时禁止启动：

- EtherCAT 未进入正常运行状态。
- 伺服未就绪或存在报警。
- 零点无效。
- 已有运动命令正在执行。
- 速度档位或运动参数无效。
- 自动模式目标位置超出软件限位。
- 当前状态需要先确认或复位故障。

运行过程中禁止切换手动/自动模式、修改传动比或重新设零。

通信故障、伺服故障、EtherCAT 故障、软件限位拒绝、自动中止和零点失效使用不同的状态码。故障原因未消除且轴未停止时不得复位。

PLC 程序预留实体急停输入和安全停机状态。后续实体急停应按照驱动器和安全回路要求直接实现安全停机，不得只通过 Windows、Modbus TCP 或普通 PLC 软件实现。

## 12. 当前调试安全限制

由于当前没有实体急停按钮：

- 只允许平台空载、人员远离旋转和夹伤区域时调试。
- 初始调试模式将最大速度限制为 1°/s。
- 首次调试优先在电机与负载分离的条件下进行；无法分离时采用平台空载。
- 电脑软件停止和通信心跳保护只能降低风险，不能替代实体急停。
- 实体急停安装并完成验证后，才进行 2、4、5、10°/s 的正式整机测试。

## 13. 验收测试

按以下顺序验收：

1. 在电机与负载分离或平台空载条件下，验证伺服使能、停止和实际方向。
2. 人工设零后，以 1°/s 分别运行 +10° 和 -10°，核对刻度方向和 PLC 角度方向一致。
3. 手动运行期间断开电脑网络，确认 PLC 在心跳超时后自动平滑停止。
4. 自动运行期间断开电脑网络，确认 PLC 同样自动平滑停止并将运行标记为中止。
5. 以 1°/s 完成正向和反向各一圈，核对指针、PLC 目标位置、最终位置和实际用时。
6. 验证 +360° 不能继续正转，-360° 不能继续反转。
7. 在中间位置测试正反方向的手动停止、重新启动和自动目标越界拒绝。
8. 断电重启，验证绝对编码器状态正常时人工零点得到保持。
9. 模拟或触发伺服、EtherCAT 和参数错误，验证运动被禁止且故障信息明确。
10. 分别在手动停止、自动完成和自动中止条件下导出 CSV，验证角度序号连续、方向正确、状态正确且数据不会被下一次测试覆盖。
11. 在 10°/s 条件下验证自动完成测试具有 1°～360°共 360 条记录，没有重复或漏点。
12. 对 PLC 事件时间与 Windows 换算时间进行重复对比，记录实际对时误差和最大抖动，不把 1 ms 分辨率直接当作 1 ms 精度。
13. 模拟 CSV 保存失败和电脑断线，验证 PLC 缓冲数据在重新连接后仍能读取。
14. 实体急停安装并验证后，依次测试 2、4、5、10°/s，并记录实际一圈用时。
15. 使用转台刻度或独立测角方法记录正反转物理角度误差，再决定是否设置反向间隙补偿。

验收通过至少要求：

- 任意电脑命令均不能使 PLC 越过 -360°～+360° 软件限位。
- 自动模式的编码器换算目标位移为准确的 ±360°，运动完成后轴处于停止状态且没有伺服报警。
- 电脑重复连接不会导致电机意外启动。
- 软件停止和心跳停止在手动、自动模式中均有效。
- 物理角度误差被单独测量和记录，不以电机编码器换算值代替输出端实测结果。
- 自动完成测试的逐度记录从 1°连续到 360°，无重复、无漏点，CSV 保存失败时原始事件仍可恢复。
- 时间字段具有 1 ms 记录分辨率，Windows—PLC 实际换算误差具有可复现的验收记录。
